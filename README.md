# KuryArt Website

Website for the company KuryArt. Made with [Astro](https://astro.build) and [Solid](https://www.solidjs.com).

## About KuryArt

KuryArt is a brazilian company with the mission of making softwares like games, sites and apps. Founded in 2022, it worked in B2B and B2C, having worked for small companies and big companies like XP Inc.
